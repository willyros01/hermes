FIDUNIO Clean Baseline

This is a one-time development cleanup. It preserves this installation's current E2EE device identity and local PIN/security material.

It deactivates other active cloud device registrations for this signed-in account, clears local test app-state/history/Outbox, and removes obsolete account vault databases. It does not delete cloud conversations/messages.

Open normal FIDUNIO in this Safari first and remain signed in.

The cleanup button is enabled only after inspection. It aborts if the current device ID changes between inspection and cleanup.

HERMES / FIDUNIO MEMORY — 0.7.0

0.6.5 passed full reliability: live messaging, offline cold-start history, repeated offline/online,
Outbox survival, automatic reconnect delivery. Preserve its local-first architecture.

0.7.0 begins direct-message E2EE:
- non-exportable per-installation ECDH P-256 private key in IndexedDB
- public JWK published to own Firestore user profile
- ECDH shared secret -> HKDF-SHA-256 -> AES-256-GCM
- fresh 12-byte IV/message; conversation ID is AES-GCM AAD
- Firestore new direct message text="" and contains ciphertext/iv/e2ee=1
- recipient decrypts locally
- encrypted local history/Outbox retained

Limitations: one-installation-per-account assumption; no multi-device fan-out, safety-number/QR,
key-change warning, Double Ratchet/forward secrecy, or group E2EE. Metadata remains visible.
Old messages remain legacy plaintext.

Included firestore.rules MUST be published.
firebase-config.js and config-firestore.js remain protected/excluded.

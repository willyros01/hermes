HERMES / FIDUNIO 0.8.1.4 — IPAD TWO-PANE FIX

PURPOSE
Corrects two UI defects in 0.8.1.3. This is a UI-only patch.

FIXED
- iPad/wide-screen Messages now immediately uses the approved two-pane layout.
- Conversation list stays on the left and the active conversation appears on the right.
- The corrupted upper-right Settings icon is fixed.
- Tablet sidebar now has proper Settings and New Conversation graphic buttons.
- Compact 4×2 colored attachment icons are retained.
- Narrow iPhone layout remains single-pane.

NO BACKEND/SECURITY CHANGES
- No Firebase changes.
- No Firestore rules changes.
- No E2EE changes.
- No device-identity or key-verification changes.
- No Outbox/history/reconnect changes.

GITHUB
1. Upload the ZIP contents to the ROOT of the existing hermes repository.
2. Preserve your existing firebase-config.js and config-firestore.js.
3. Overwrite hermes-memory.txt and hermes-setup.txt with these current copies.
4. Confirm root version.js shows 0.8.1.4.
5. No Firestore Rules publication is required.

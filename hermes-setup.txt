HERMES / FIDUNIO 0.8.1.1 — 2D ICON UI REFINEMENT

PURPOSE
0.8.1.1 is a UI-only release built from the fully passed 0.8.1 key-verification baseline.

WHAT CHANGED
- Replaced simple text/emoji-like action graphics with cleaner two-dimensional SVG pictograms.
- Updated Settings, New/Add, Back, Info, Send, and the composer tool-panel graphics.
- Composer tools now use consistent 2D icons for Photo, File, Voice, Location, Contact, Checklist, Schedule, and Saved.
- Preserved the approved navy/teal/gray palette; no gold was added.

WHAT DID NOT CHANGE
- Firebase configuration
- Firestore rules
- E2EE ciphertext format
- Device identity
- Contact key verification
- Outbox
- Offline local history
- Reconnect/listener behavior
- Conversation data model

GITHUB UPDATE
1. Upload the files from this release ZIP to the ROOT of the existing hermes repository.
2. Keep your existing firebase-config.js and config-firestore.js untouched; they are intentionally excluded.
3. Replace the existing root-level hermes-memory.txt and hermes-setup.txt with the copies from this release.
4. Commit and wait for GitHub Pages deployment.
5. Open version.js in GitHub and confirm it says version: "0.8.1.1".

FIRESTORE
No Firestore rules update is required. The rules are unchanged from 0.8.1 / 0.8.0.

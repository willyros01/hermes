HERMES / FIDUNIO 0.8.1.9 — ORIENTATION-AWARE TABLET UI

PURPOSE
UI-only refinement so iPad portrait and landscape no longer use the exact same secondary-screen proportions.

WHAT CHANGED
- Portrait iPad/tablet:
  keeps the centered single-column tablet layout.
- Landscape iPad/tablet:
  uses the available width more naturally.
- Settings:
  two-column card layout on wide landscape tablets.
- First/unlock screen:
  wider centered card in landscape.
- New Message / New Group / Group Name:
  broader centered workspace in landscape.
- Messages/chat:
  existing two-pane layout remains unchanged.
- iPhone/narrow screens:
  unchanged.

NO SECURITY/BACKEND CHANGES
No Firebase, Firestore Rules, E2EE, contact-key verification, device identity, Outbox, local history, or reconnect changes.

GITHUB
1. Upload ZIP contents to the ROOT of the hermes repository.
2. Preserve firebase-config.js and config-firestore.js.
3. Overwrite hermes-memory.txt and hermes-setup.txt.
4. Confirm version.js shows 0.8.1.9.
5. No Firestore Rules publication is required.

TEST
1. iPad portrait:
   - Unlock, Settings, New Message remain centered and balanced.
2. Rotate to landscape:
   - Unlock becomes wider and centered.
   - Settings should use two columns on a wide iPad.
   - New Message/New Group should use more of the screen width.
3. Messages/chat:
   - two-pane layout remains.
4. iPhone:
   - existing single-pane behavior remains.
